# Архитектурные принципы

1. Не изобретай велосипед — используй готовые решения
2. Skills-first — Developer заполняет шаблоны
3. Гибрид моделей — облако для мышления, локалка для рутины
4. Tool Use — LLM сам вызывает инструменты
5. Git + бэкапы — любое изменение обратимо
6. Автономность — система работает без копипаста
7. Память исключена из бэкапов — избегаем рекурсии
