# Архитектура агентов

Каждый агент — это agent.yaml + роль + инструменты + права + память.

Список агентов:
- CEO — стратегия, управление (/ceo)
- Architect — архитектура (/architect)
- Reviewer — проверка кода (/reviewer)
- Strategist — генерация идей (/strategist)
- Monetizer — заработок (/monetizer)
- Researcher — исследования (/researcher)
- Negotiator — переговоры (/negotiator)
- Documentarian — документация (/document)
- Tester — тестирование (/tester)
- Analytics — метрики (/analytics)
