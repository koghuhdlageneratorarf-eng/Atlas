# ATLAS ROADMAP vNext
**Цель:** максимально быстро сделать Atlas способным разрабатывать самого себя.

---

# Главный принцип

LLM — не Atlas.

Atlas — это Runtime, который использует LLM как вычислительный модуль.

```
        User / Open WebUI
               │
               ▼
          Atlas Runtime
               │
      ┌────────┴────────┐
      │                 │
 Context Builder     Tool Registry
      │                 │
      └────────┬────────┘
               ▼
             Router
               ▼
              LLM
               ▼
         Patch Engine
               ▼
         Validation
               ▼
          Git Manager
```

---

Потом — полуавтономным агентом.

Потом — автономным Code Agent.

# Runtime

Runtime — главный цикл Atlas.

```
Task

↓

Analyze

↓

Collect Context

↓

Execute

↓

Generate Patch

↓

Apply Patch

↓

Validate

↓

Review

↓

Done
```

Все задачи проходят через Runtime.

---

# Основные компоненты

## Runtime

Отвечает за выполнение задачи.

Не знает ничего о моделях.

---

## Router

Выбирает модель.

Поддерживает:

- Ollama
- OpenRouter
- Gemini
- Groq
- Cloudflare
- Local

---

## Context Builder

Автоматически собирает контекст.

Компоненты:

- File Selector
- Dependency Scanner
- Symbol Resolver
- Prompt Builder

---

## Tool Registry

Единая регистрация инструментов.

Пример:

- read_file
- write_patch
- grep
- bash
- git
- search
- memory

---

## Patch Engine

Единственный способ изменения файлов.

Запрещено:

- полная перезапись файла

Разрешено:

- search/replace
- unified diff
- AST patch (в будущем)

---

## Validator

Проверяет:

- patch
- syntax
- formatter
- linter
- tests

---

## Reviewer

Проверяет результат.

Возвращает задачу Executor при ошибке.

---

## Git Manager

Отвечает за:

- backup
- diff
- commit
- rollback

---

## Session Manager

Хранит состояние выполнения.

- task
- steps
- files
- attempts
- history

# Roadmap

## Phase 0 — Cleanup

Цель:

Подготовить архитектуру.

### Задачи

- [ ] Создать atlas_core
- [ ] Перенести Runtime
- [ ] Перенести Router
- [ ] Перенести Tools
- [ ] Перенести Memory
- [ ] Удалить старые pipeline
- [ ] Вынести Studio-функции в Skills

---

## Phase 1 — Bootstrap

Цель:

Полностью перейти на Atlas + Open WebUI.

### Задачи

- [ ] OpenAI API
- [ ] Open WebUI
- [ ] Router
- [ ] Tool Calling
- [ ] История чата
- [ ] Streaming
- [ ] Стабильная работа локальных моделей

После этого ChatGPT нужен только как резерв.

---

## Phase 2 — Developer Assistant

Цель:

Atlas понимает собственный код.

### Возможности

- читать проект

- искать зависимости

- объяснять архитектуру

- отвечать

"где изменить"

"что удалить"

"что сломается"

Без изменения файлов.

### Задачи

- [ ] Context Builder
- [ ] File Selector
- [ ] Symbol Resolver
- [ ] Project Index
- [ ] Dependency Scanner

---

## Phase 3 — Self Editing

Цель:

Atlas начинает менять себя.

### Возможности

- создать patch

- показать diff

- применить изменения

### Задачи

- [ ] Patch Engine
- [ ] Diff Preview
- [ ] Apply Patch
- [ ] Backup
- [ ] Undo

---

## Phase 5 — Git Integration

### Задачи

- [ ] Backup

## Phase 6 — Autonomous Development

Цель:

Atlas способен реализовывать небольшие задачи самостоятельно.

- анализирует проект

- находит нужные файлы

- создаёт patch

- запускает проверки

- показывает diff

- ждёт подтверждения

# Критерии готовности

## M1

Работа только через Atlas + WebUI.

❌ ChatGPT больше не нужен.

---

## M2

Atlas отвечает по своему коду.

---

## M3

Atlas умеет менять собственные файлы.

---

## M4

Atlas проходит цикл:

Task → Patch → Validation → Review.

Atlas способен реализовать небольшую задачу без участия человека.
